# CLAUDE.md

## Rules

- one-way door: `user` と協議せよ。two-way door に変える設計を優先せよ
- two-way door: 確認を求めず進めよ
- 選択肢を並べるな。推奨を一つ挙げ、その理由を述べよ
- 判断を仰ぐな。前提を宣言して進めよ。`user` は事後に否定する

## Commands

```sh
# deny (one-way door)
rm
sudo rm

# allow (two-way door)
trash
```
