# Academic Test: Systematic Debugging Skill

skills/debugging/systematic-debugging にある systematic debugging skill を使えます。

skill を読み、その skill に書かれていることだけに基づいて、以下の質問に答えてください。

1. 体系的な debug の 4 つの phase は何ですか
2. どんな修正を試みる前にも、必ずすべきことは何ですか
3. Phase 3 で、最初の仮説が外れたらどうすべきですか
4. 複数のことを同時に直すことについて、skill は何と言っていますか
5. 問題を完全には理解していないとき、どうすべきですか
6. 単純な bug なら手順を飛ばしてよい場合はありますか

該当する箇所は、skill からの直接の引用を添えて答えてください。
