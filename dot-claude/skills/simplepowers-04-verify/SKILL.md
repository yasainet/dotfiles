# Verify

## Do

- `Build` で実装したコード・文章に対して、検証を実行せよ
  - `./README.md` の Verify section に従え。section がなければ `user` に更新を促せ
  - 出力と exit code を最後まで読め

Tools:

| When             | Tools                           |
| ---------------- | ------------------------------- |
| 検証の実行       | `./README.md` の Verify section |
| app の挙動を確認 | `/run`                          |

## Don't

- 検証が失敗したまま先に進むことを禁止する。`Explore`, `Plan`, `Build` に戻れ

## Done

検証が通ったら `Review` へ移行せよ。
