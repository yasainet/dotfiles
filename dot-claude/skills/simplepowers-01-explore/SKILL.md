# Explore

## Do

- 質問・目的 (Goal) の対象を、深く詳細に調査をせよ
- 調査対象の公式情報と最新情報、およびコミュニティの情報を調査せよ
- 調査対象の内部情報 (コード・文章)、外部情報 (Web) を調査せよ

## Don't

- ファイルの編集を禁止する

## Done

- 目的 (Goal) が決定したら、 `Plan` へ移行せよ

## Tools

| When                     | Tools                               |
| ------------------------ | ----------------------------------- |
| 内部の探索範囲           | `@Explore`                          |
| 外部の探索範囲           | `@general-purpose`, `deep-research` |
| 最新の情報を引く         | `context7`                          |
| Claude Code の仕様を引く | `claude-code-guide`                 |
