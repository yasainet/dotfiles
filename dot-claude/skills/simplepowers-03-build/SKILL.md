# Build

Start by declaring `[Build]`.

## Purpose

`Plan` で承認した設計を実装する。

## Scope

- `Plan` で承認した設計を実装せよ
- `Plan` にはない変更がある場合は `user` に伝えて、`Explore` に戻れ

## Responsibilities

N/A

## Procedure

Documents:

1. `Plan` に従って更新せよ
2. `Verify` へ移行せよ

Developments:

1. `tdd.md` の手順に従え
2. `Plan` にはない変更がある場合は `user` に伝えて、`Explore` に戻れ
3. `Verify` へ移行せよ
